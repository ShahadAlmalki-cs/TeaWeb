# 🍵 ركن شهد لنكهات الشاي

تجربة ويب تفاعلية هادئة لاستكشاف نكهات الشاي وفوائدها، مع اختبار تفاعلي لاكتشاف النكهة التي تناسب مزاجك.

### المميزات
- استعراض أنواع الشاي وتفاصيلها بتصميم ناعم ومريح.
- اختبار تفاعلي خفيف لمعرفة نكهتك المفضلة.
- واجهة متجاوبة وأنيقة تدعم اللغة العربية.

# 🍵 Shahad's Tea Corner

A minimal, interactive web experience exploring tea flavors, benefits, and a short quiz to match your mood with a tea blend.

### Features
- Interactive showcase of tea varieties with calm aesthetics.
- Quick personality quiz to discover your tea match.
- Clean, responsive Arabic (RTL) interface.
